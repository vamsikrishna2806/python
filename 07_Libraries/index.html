📚 Python Libraries

Superpower Your Code with Pre-Built Tools

🎯 Why Libraries Matter

A library (or module) is pre-written code that solves common problems. Instead of coding everything from scratch, you reuse battle-tested code written by experts.

Analogy: Building a house from scratch means making bricks, lumber, nails, etc. Using libraries means buying pre-made materials and focusing on construction!

📦 Installing & Importing Libraries

BEGINNER Installation

Before using a library, you must install it with pip (Python's package manager):

# In your terminal/command prompt:
pip install numpy
pip install pandas
pip install matplotlib
ℹ️ Tip: You only need to install once. After that, it's on your computer forever!
BEGINNER Three Ways to Import
# Way 1: Import entire library
import numpy
arr = numpy.array([1, 2, 3])

# Way 2: Import with alias (preferred!)
import numpy as np
arr = np.array([1, 2, 3]) # Shorter!

# Way 3: Import specific functions
from numpy import array
arr = array([1, 2, 3])
✅ Best Practice: Use Way 2 (with aliases) - it's the standard in the Python community!

🔢 NumPy: Fast Mathematical Arrays

BEGINNER What is NumPy?

NumPy gives Python super-powers for math! It makes arrays (lists of numbers) that are:

  • ✅ 100x faster than Python lists
  • ✅ Use less memory
  • ✅ Easy math operations
  • ✅ Professional grade numerical computing
BEGINNER Creating NumPy Arrays
import numpy as np

# From a Python list
arr1 = np.array([1, 2, 3, 4, 5])

# Create arrays of zeros or ones
zeros = np.zeros(5) # [0, 0, 0, 0, 0]
ones = np.ones(3) # [1, 1, 1]

# Create range of numbers
range_arr = np.arange(0, 10, 2) # [0, 2, 4, 6, 8]

# Create evenly spaced numbers
linspace = np.linspace(0, 100, 5) # [0, 25, 50, 75, 100]
INTERMEDIATE Array Operations

NumPy makes math on entire arrays simple:

import numpy as np

arr = np.array([1, 2, 3, 4, 5])

# Math on entire array at once!
doubled = arr * 2 # [2, 4, 6, 8, 10]
squared = arr ** 2 # [1, 4, 9, 16, 25]

# Statistical functions
total = arr.sum() # 15
average = arr.mean() # 3.0
max_val = arr.max() # 5
std_dev = arr.std() # Standard deviation

📊 Pandas: Excel-Like Data Analysis

INTERMEDIATE What is Pandas?

Pandas gives you DataFrames

Think of it as: Excel + Python superpowers

Creating DataFrames

import pandas as pd

# Create from dictionary
data = {
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'Score': [90, 85, 95]
}

df = pd.DataFrame(data)
print(df)
INTERMEDIATE DataFrame Operations
import pandas as pd

# Access columns
names = df['Name'] # Get Name column

# Get rows
first_row = df.iloc[0] # First row

# Filtering
adults = df[df['Age'] > 25] # Age > 25

# Sorting
sorted_df = df.sort_values('Score') # Sort by score

# Statistics
avg_age = df['Age'].mean() # Average age
stats = df.describe() # All statistics
