🎨 Matplotlib Basics

BEGINNER Introduction to Matplotlib

Matplotlib is Python's most popular visualization library. It's simple yet powerful—perfect for learning data visualization!

Your First Chart

import matplotlib.pyplot as plt

# Prepare data
days = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri']
temperatures = [20, 22, 19, 24, 25]

# Create line plot
plt.figure(figsize=(10, 6)) # Size: 10 wide, 6 tall
plt.plot(days, temperatures, marker='o')

# Add labels
plt.title('Weekly Temperature', fontsize=16)
plt.xlabel('Days')
plt.ylabel('Temperature (°C)')
plt.grid(True) # Add grid lines

plt.show()
✅ That's it! Just 10 lines creates a professional chart.
BEGINNER Chart Parts Explained
Title: What is the chart about?
X-Axis: Horizontal values
Y-Axis: Vertical values
Data Points: The actual values
Legend: What each color means
Grid: Background lines for reading
Markers: Dots on data points
Colors: Make it visually appealing
Labels: Axis descriptions

📈 Chart Types & When to Use Them

1️⃣ Line Chart - Show Trends Over Time

BEGINNER

Best for: Temperature changes, stock prices, website traffic

import matplotlib.pyplot as plt

months = ['Jan', 'Feb', 'Mar', 'Apr']
sales = [100, 120, 110, 140]

plt.plot(months, sales, marker='o', linewidth=2)
plt.title('Monthly Sales')
plt.ylabel('Sales ($)')
plt.show()

2️⃣ Bar Chart - Compare Categories

BEGINNER

Best for: Comparing sales by country, product ratings, survey results

import matplotlib.pyplot as plt

products = ['Laptop', 'Phone', 'Tablet']
sales = [300, 450, 200]
colors = ['#667eea', '#764ba2', '#f093fb']

plt.bar(products, sales, color=colors)
plt.title('Product Sales')
plt.ylabel('Sales Units')
plt.show()

3️⃣ Scatter Plot - Show Relationships

INTERMEDIATE

Best for: Relationship between two variables, clusters in data

import matplotlib.pyplot as plt

ages = [20, 25, 30, 35, 40]
salaries = [30000, 45000, 60000, 75000, 90000]

plt.scatter(ages, salaries, s=100, alpha=0.6)
plt.title('Age vs Salary')
plt.xlabel('Age')
plt.ylabel('Salary ($)')
plt.show()

4️⃣ Histogram - Show Distribution

INTERMEDIATE

Best for: Test scores, height distribution, price ranges

import matplotlib.pyplot as plt

scores = [65, 72, 78, 85, 88, 90, 92, 95]

plt.hist(scores, bins=5, color='#667eea', edgecolor='black')
plt.title('Test Score Distribution')
plt.xlabel('Scores')
plt.ylabel('Frequency')
plt.show()

5️⃣ Pie Chart - Show Percentages

BEGINNER

Best for: Market share, budget breakdown, survey percentages

import matplotlib.pyplot as plt

categories = ['Food', 'Rent', 'Entertainment', 'Savings']
amounts = [30, 40, 20, 10]
colors = ['#667eea', '#764ba2', '#f093fb', '#f5576c']

plt.pie(amounts, labels=categories, colors=colors, autopct='%1.1f%%')
plt.title('Budget Breakdown')
plt.show()

🎨 Make Beautiful Charts

INTERMEDIATE Styling & Customization

Key Styling Options

import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [10, 20, 15, 25, 30]

# Create figure with custom size
plt.figure(figsize=(12, 6))

# Plot with styling
plt.plot(x, y,
    marker='o', # Dot markers
    linewidth=3, # Thicker line
    color='#667eea', # Custom color
    label='Revenue' # For legend
)

# Customize chart
plt.title('Quarterly Revenue', fontsize=16, fontweight='bold')
plt.xlabel('Quarter', fontsize=12)
plt.ylabel('Revenue ($1000s)', fontsize=12)
plt.legend() # Show legend
plt.grid(True, alpha=0.3)
plt.tight_layout() # Auto adjust spacing
plt.show()

🎯 Challenge: Build a Dashboard

ADVANCED Create Multiple Charts

Create a dashboard with multiple charts showing different data:

import matplotlib.pyplot as plt

# Create 2x2 dashboard
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# Chart 1: Line chart (top left)
axes[0, 0].plot([1, 2, 3], [10, 20, 15])
axes[0, 0].set_title('Line Chart')

# Chart 2: Bar chart (top right)
axes[0, 1].bar(['A', 'B', 'C'], [10, 20, 15])
axes[0, 1].set_title('Bar Chart')

# Chart 3: Histogram (bottom left)
axes[1, 0].hist([1, 2, 2, 3, 3, 3])
axes[1, 0].set_title('Histogram')

# Chart 4: Scatter (bottom right)
axes[1, 1].scatter([1, 2, 3], [5, 10, 15])
axes[1, 1].set_title('Scatter Plot')

plt.tight_layout()
plt.show()

✨ Key Takeaways

✅ Chart Types:
• Line: Trends over time (sales, temperature)
• Bar: Compare categories (products, countries)
• Scatter: Relationships (age vs income)
• Histogram: Distribution (scores, heights)
• Pie: Percentages (budget breakdown)

✅ Styling Matters:
• Colors make charts attractive
• Clear labels help understanding
• Grid lines aid reading
• Size (figsize) affects readability

🎯 Golden Rule:
"Choose the right chart type for your data story!"
