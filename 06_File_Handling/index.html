📄 File Handling

Master Reading, Writing, and Managing Files

🎯 What is File Handling?

File handling is one of the most important skills in programming. It allows you to permanently store data on your computer that persists even after your program stops running.

Why Files Matter:
✓ Save user data between program runs
✓ Store configuration settings
✓ Manage large datasets
✓ Share data with other programs
✓ Create logs and reports

Real-World Examples

📱 Mobile Apps: Store user preferences and app data

🎮 Games: Save game progress and high scores

📊 Data Science: Read CSV files with thousands of records

🌐 Web Apps: Store user accounts, posts, messages

📚 File Basics

BEGINNER Understanding Files

A file is simply a collection of data stored on your hard drive. Every file has:

📝 Filename The name of the file (e.g., "notes.txt")
📂 Path Location on disk (e.g., "D:/documents/notes.txt")
📋 Extension Type indicator (e.g., .txt, .json, .csv)
💾 Content The actual data stored in the file

File vs Memory

1
Variables in Memory (RAM) - Lost when program closes
2
Files on Disk (Storage) - Persist forever
3
Your Program - Reads/writes files as needed
# Without files - data is lost!
name = "Alice"
score = 95
print(f"Hello {name}, your score: {score}")
# Program ends → data GONE!

# With files - data is saved!
with open('score.txt', 'w') as file:
    file.write(f"Name: {name}\nScore: {score}")
# Program ends → data SAVED!

🔑 File Modes Explained

BEGINNER The 4 Essential Modes

When you open a file, you must tell Python what you want to do with it. These are the main modes:

Mode Name What It Does Example
'r' Read Open existing file to read. File must exist! open('data.txt', 'r')
'w' Write Create new file or overwrite existing. ⚠️ Deletes old content! open('data.txt', 'w')
'a' Append Add content to end of file. Keeps existing data. open('data.txt', 'a')
'x' Create Create new file only. Fails if file exists. open('data.txt', 'x')
⚠️ Important: Mode 'w' overwrites files! Always be careful not to lose data.

Visual Comparison

Read Mode ('r'):
File: [Hello World]
Action: Look inside without changing
Result: File stays [Hello World]

Write Mode ('w'):
File: [Hello World]
Action: Replace everything
Result: File becomes [New Content]

Append Mode ('a'):
File: [Hello World]
Action: Add to the end
Result: File becomes [Hello World] + [New]

📖 Reading Files - Three Ways

BEGINNER Method 1: read() - Read Everything

Get the entire file contents as a single string:

# Read entire file at once
with open('story.txt', 'r') as file:
    all_content = file.read()
    print(all_content)

# Good for: Small files you want all at once
✅ Best for: Reading entire small files (scripts, configs)
❌ Bad for: Huge files (will use lots of memory)
INTERMEDIATE Method 2: readlines() - Get List of Lines

Read file as a list where each element is one line:

# Read file as list of lines
with open('students.txt', 'r') as file:
    lines = file.readlines()
    print(lines[0]) # First line
    print(lines[2]) # Third line

# Each line includes the \n character!
✅ Best for: Accessing specific lines, files with structure
❌ Note: Each line keeps the \n newline character
ADVANCED Method 3: Loop Through Lines (Most Efficient)

Read line-by-line in a loop - best for large files:

# Loop through file line by line (BEST WAY!)
with open('huge_file.txt', 'r') as file:
    for line in file:
        print(line.strip()) # strip() removes \n

# Process line by line - memory efficient!
✅ Best for: Large files, processing data line by line
✅ Memory efficient: Doesn't load entire file at once

⚡ Try All Three Reading Methods

✍️ Writing & Appending Files

BEGINNER Writing (Creating Files)

Create a new file or overwrite existing content:

# Write to file - creates new or overwrites
with open('output.txt', 'w') as file:
    file.write("First line\n")
    file.write("Second line\n")
    file.write("Third line")
⚠️ Caution: 'w' mode overwrites everything! The old content is gone.
BEGINNER Appending (Adding to Files)

Add content to the END of a file without losing existing data:

# Append to file - keeps existing content
with open('log.txt', 'a') as file:
    file.write("\nNew log entry")

# If file doesn't exist, it creates it
# If file exists, it adds to the end
✅ Safe choice: Use 'a' when you want to keep existing data

⚡ Try Writing and Appending

Opening Files

Use the open() function with different modes:

Mode Description Example
'r' Read (default) open('file.txt', 'r')
'w' Write (creates/overwrites) open('file.txt', 'w')
'a' Append (add to end) open('file.txt', 'a')
'x' Create (fails if exists) open('file.txt', 'x')

Reading Files

# Read entire file
with open('data.txt', 'r') as file:
    content = file.read()
    print(content)

# Read line by line
with open('data.txt', 'r') as file:

Writing Files

    file.write("Hello, World!\n")
    file.write("This is a test.")

# Append to file
with open('output.txt', 'a') as file:
    file.write("\nAdded new line!")

🔒 The 'with' Statement (Always Use This!)

BEGINNER Closing Files Automatically

When you open a file, Python keeps it open until you close it. The with statement closes files automatically:

# ❌ OLD WAY - Manual closing (risky!)
file = open('data.txt', 'r')
content = file.read()
file.close() # Easy to forget!

# ✅ BETTER WAY - Auto closing (safe!)
with open('data.txt', 'r') as file:
    content = file.read()
# File automatically closes here!
✅ Always use 'with'! It's safer and cleaner.

Why This Matters

  • ✓ Prevents file corruption if program crashes
  • ✓ Prevents other programs from accessing incomplete files
  • ✓ Frees up memory automatically
  • ✓ Cleaner, more readable code

🔄 Working with JSON (Data Format)

INTERMEDIATE JSON: The Universal Data Format

JSON (JavaScript Object Notation) is the most popular data format for storing and exchanging data. It looks like Python dictionaries and lists!

Why JSON?
✓ Used by all modern websites (Twitter, Facebook, etc)
✓ Easy to read and write
✓ Works with every programming language
✓ Perfect for APIs and web services

JSON vs Python Objects

Python Dictionary:
{"name": "Alice", "age": 30}

JSON (text):
{"name": "Alice", "age": 30}

Looks the same! JSON is just text that looks like Python.
INTERMEDIATE Writing JSON Files
import json

# Create a Python dictionary
person = {
    "name": "Alice",
    "age": 30,
    "city": "New York",
    "hobbies": ["reading", "coding"]
}

# Save to JSON file
with open('person.json', 'w') as file:
    json.dump(person, file, indent=2)
# indent=2 makes it readable!
INTERMEDIATE Reading JSON Files
import json

# Read JSON file back to Python
with open('person.json', 'r') as file:
    data = json.load(file)

# Now it's a normal Python dictionary!
print(data['name']) # Alice
print(data['age']) # 30
print(data['hobbies']) # ['reading', 'coding']

⚠️ Error Handling (Handle Problems Gracefully)

ADVANCED Common File Errors

Files can fail for many reasons. Good programmers handle errors gracefully:

Error Cause Solution
FileNotFoundError File doesn't exist Check if file exists first, use 'a' mode instead
PermissionError No access rights Check file permissions
json.JSONDecodeError Invalid JSON format Validate JSON before reading
IOError Disk full or hardware issue Check disk space

Try-Except Pattern (Best Practice)

try:
    with open('data.txt', 'r') as file:
        content = file.read()
        print(f"Read {len(content)} characters")

except FileNotFoundError:
    print("❌ File not found! Creating new file...")
    with open('data.txt', 'w') as file:
        file.write("New file content")

except PermissionError:
    print("❌ No permission to access file!")

🌟 Real-World Patterns

ADVANCED Pattern 1: Read and Process

Read a file line-by-line, process each line, and save results:

# Pattern: Read, Process, Write
with open('input.txt', 'r') as infile:
    with open('output.txt', 'w') as outfile:
        for line in infile:
            processed = line.strip().upper()
            outfile.write(processed + '\n')
ADVANCED Pattern 2: Configuration Files
import json

# Save settings
config = {
    "username": "alice",
    "theme": "dark",
    "language": "en"
}

with open('config.json', 'w') as f:
    json.dump(config, f)

# Load settings later
with open('config.json', 'r') as f:
    config = json.load(f)
    print(f"Welcome {config['username']}")

🎯 Challenge Project

ADVANCED Build: Personal Note-Taking App

Create a simple app that:

  • ✅ Saves notes to a JSON file
  • ✅ Loads notes when program starts
  • ✅ Shows saved notes to user
  • ✅ Handles errors gracefully
import json

class NoteApp:
    def __init__(self):
        self.filename = 'notes.json'
        self.notes = self.load_notes()

    def load_notes(self):
        try:
            with open(self.filename, 'r') as f:
                return json.load(f)
        except:
            return []

    def add_note(self, title, text):
        self.notes.append({"title": title, "text": text})
        self.save_notes()

    def save_notes(self):
        with open(self.filename, 'w') as f:
            json.dump(self.notes, f, indent=2)
