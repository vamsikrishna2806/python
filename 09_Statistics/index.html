📊 Descriptive Statistics (Describe Your Data)

BEGINNER The 5 Numbers You Need to Know
Statistic What It Means Example
Mean (Average) Add all values, divide by count [10,20,30] → mean=20
Median (Middle) Middle value when sorted [10,20,30] → median=20
Mode (Most Common) Value that appears most [1,1,2,3,3,3] → mode=3
Range Max - Min [10,20,30] → range=20
Std Dev How spread out is the data? Small=clustered, Large=spread

Calculate Statistics

import statistics

# Sample data
scores = [85, 90, 88, 92, 87, 85, 91]

# Calculate statistics
mean = statistics.mean(scores) # 88.3
median = statistics.median(scores) # 88
stdev = statistics.stdev(scores) # 2.67

print(f"Mean: {mean:.1f}")
print(f"Median: {median}")
print(f"Std Dev: {stdev:.2f}")

🎲 Probability (Chance & Randomness)

INTERMEDIATE What is Probability?

Probability = chance that something happens

Coin Toss: P(Heads) = 1/2 = 0.5 = 50%
Dice Roll: P(Rolling 6) = 1/6 ≈ 16.7%
Weather: 80% chance of rain tomorrow

Always between 0 and 1:
0 = impossible, 0.5 = 50/50, 1 = certain

Random Number Generation

import random

# Random integer between 1-100
dice_roll = random.randint(1, 6)

# Random float between 0-1
probability = random.random()

# Random choice from list
coin = random.choice(['heads', 'tails'])

# Shuffle a list
cards = [1, 2, 3, 4, 5]
random.shuffle(cards)

# Random sample (no replacement)
winners = random.sample([1, 2, 3, 4, 5], k=2)

📊 Probability Distributions

ADVANCED Normal Distribution (Bell Curve)

The most common distribution in nature! Heights, test scores, IQ—all follow this pattern:

Bell Curve Properties:
• 68% of data within 1 std dev
• 95% of data within 2 std devs
• 99.7% of data within 3 std devs
• Symmetric around mean
• Most values near center

Working with Distributions

import random

# Normal distribution (bell curve)
# Mean=100, StdDev=15 (like IQ scores)
iq_score = random.gauss(mu=100, sigma=15)

# Generate multiple scores
iq_scores = [random.gauss(100, 15) for _ in range(1000)]

# Create histogram to visualize
import matplotlib.pyplot as plt
plt.hist(iq_scores, bins=30)
plt.title('IQ Score Distribution')
plt.xlabel('IQ Score')
plt.ylabel('Frequency')
plt.show()

🔗 Correlation & Relationships

ADVANCED Finding Patterns in Data

Correlation: Do two variables move together?

Correlation Coefficient (r):
+1.0 = Perfect positive (both increase together)
0.0 = No relationship
-1.0 = Perfect negative (one increases, other decreases)

Examples:
Height & Weight: +0.8 (positive)
Speed & Time to Finish: -0.9 (negative)
Shoe Size & IQ: 0.0 (no correlation)

Calculate Correlation

import statistics

# Data: Hours studied vs Test Score
hours = [1, 2, 3, 4, 5]
scores = [60, 70, 75, 85, 90]

# Calculate correlation coefficient
n = len(hours)
mean_h = statistics.mean(hours)
mean_s = statistics.mean(scores)

# Covariance calculation (simplified)
covariance = sum((hours[i]-mean_h)*(scores[i]-mean_s)
                for i in range(n)) / n
