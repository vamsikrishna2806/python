🔀 Control Flow

Making Decisions & Creating Loops

❓ If/Else Statements

If/Else statements let your program make decisions based on conditions. It's like asking "Should I do this?"

Basic Structure:
if condition: → Execute if True
else: → Execute if False
elif: → Check another condition

Comparison Operators

Operator Meaning Example
== Equal to 5 == 5 → True
!= Not equal to 5 != 3 → True
> Greater than 10 > 5 → True
< Less than 3 < 7 → True
>= Greater or equal 5 >= 5 → True
<= Less or equal 5 <= 10 → True

Simple If/Else Example

age = 18 if age >= 18: print("You are an adult") else: print("You are a minor")

Logical Operators (and, or, not)

Operator Meaning Example
and Both conditions must be True (5 > 3) and (10 > 8) → True
or At least one condition is True (5 > 10) or (3 > 1) → True
not Reverses the condition not (5 > 10) → True
age = 20 has_license = True # Using 'and' if age >= 18 and has_license: print("You can drive!") else: print("You cannot drive") # Using 'or' is_weekend = True is_holiday = False if is_weekend or is_holiday: print("It's a day off!")

🔁 For Loops

For loops let you repeat code a specific number of times. Perfect for processing multiple items!

For Loop: Repeat for each item in a sequence
for item in sequence:
    # code to repeat

Counting with range()

# Count from 1 to 5 for i in range(1, 6): print(i) # Output: # 1 # 2 # 3 # 4 # 5

Try For Loops

Looping Through Lists

fruits = ["apple", "banana", "cherry"] for fruit in fruits: print(f"I like {fruit}") # Output: # I like apple # I like banana # I like cherry

Try Looping Through Lists

♾️ While Loops

While loops repeat as long as a condition is True. They're useful when you don't know how many times to repeat.

While Loop: Keep repeating while condition is True
while condition:
    # code to repeat

Simple While Loop Example

count = 1 while count <= 5: print(count) count = count + 1 # Output: # 1 # 2 # 3 # 4 # 5

Try While Loops

For vs While Loops

For Loop

✓ Known number of repeats

✓ Iterate through sequence

✓ Cleaner syntax

While Loop

✓ Unknown number of repeats

✓ Repeat until condition

✓ More flexible

⏹️ Break & Continue

Break: Exit a Loop

The break statement stops the loop immediately.

for i in range(1, 11): if i == 5: print("Stopping at 5!") break print(i) # Output: # 1 # 2 # 3 # 4 # Stopping at 5!

Continue: Skip an Iteration

The continue statement skips to the next iteration.

for i in range(1, 6): if i == 3: print("Skipping 3!") continue print(i) # Output: # 1 # 2 # Skipping 3! # 4 # 5
