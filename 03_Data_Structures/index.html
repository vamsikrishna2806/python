📦 Data Structures

Lists, Dictionaries, Sets & Tuples

📝 Lists - Ordered Collections

Lists are ordered collections of items that can be changed. Perfect for storing related data!

Key Points:
✓ Ordered (maintains position)
✓ Mutable (can be changed)
✓ Allow duplicates
✓ Use square brackets []

Creating & Accessing Lists

# Creating a list fruits = ["apple", "banana", "cherry"] # Accessing items (0-indexed) print(fruits[0]) # apple print(fruits[1]) # banana print(fruits[-1]) # cherry (last item) # List length print(len(fruits)) # 3

List Methods

Method Description Example
append() Add item to end list.append(5)
insert() Add item at position list.insert(0, 5)
remove() Remove first occurrence list.remove(5)
pop() Remove last item list.pop()
sort() Sort list list.sort()
reverse() Reverse order list.reverse()

🔑 Dictionaries - Key-Value Pairs

Dictionaries store key-value pairs for quick lookup. Like a real dictionary!

Key Points:
✓ Unordered (indexed by key)
✓ Mutable (can be changed)
✓ Use curly braces {}
✓ Access with key, not position

Creating & Using Dictionaries

# Creating a dictionary student = { "name": "Alice", "age": 20, "grade": "A" } # Accessing values print(student["name"]) # Alice print(student["age"]) # 20 # Adding new key-value pair student["email"] = "alice@email.com" # Modifying values student["age"] = 21 # Getting all keys and values print(student.keys()) print(student.values())

Try Working with Dictionaries

🎯 Sets - Unique Values

Sets are unordered collections of unique items. Perfect for removing duplicates!

Key Points:
✓ Unordered
✓ No duplicates
✓ Mutable
✓ Use curly braces {} (without colons)

Creating & Using Sets

# Creating a set colors = {"red", "green", "blue"} # Adding items colors.add("yellow") # Removing items colors.remove("blue") # Remove duplicates numbers = [1, 1, 2, 2, 3, 3] unique_numbers = set(numbers) # {1, 2, 3} # Set operations set1 = {1, 2, 3} set2 = {2, 3, 4} print(set1 | set2) # Union: {1, 2, 3, 4} print(set1 & set2) # Intersection: {2, 3}

Try Working with Sets

📌 Tuples - Immutable Sequences

Tuples are like lists but cannot be changed once created. Great for protecting data!

Key Points:
✓ Ordered (maintains position)
✓ Immutable (cannot be changed)
✓ Use parentheses ()
✓ Faster than lists

Creating & Using Tuples

# Creating a tuple coordinates = (10, 20, 30) # Accessing items (like lists) print(coordinates[0]) # 10 # Length print(len(coordinates)) # 3 # Cannot modify (this will give an error!) # coordinates[0] = 15 # Error! # Unpacking x, y, z = coordinates print(x, y, z) # Creating single item tuple single = (42,) # Note the comma!
