⚙️ Functions

Write Reusable Code

What Are Functions?

Functions are reusable blocks of code that perform specific tasks. They help you avoid repeating code and organize your programs.

Why Functions?
✓ Reuse code multiple times
✓ Keep code organized
✓ Make debugging easier
✓ Make code more readable

Function Structure

def function_name(parameters): """This is a docstring - describes what the function does""" # Function body - the code return result # Calling the function function_name(arguments)

Basic Functions

Simple Function

def greet(): print("Hello, World!") greet() # Calling the function

Try Functions

Parameters & Return Values

Parameters (inputs)

Parameters are variables that functions receive:

def calculate_age(birth_year, current_year): age = current_year - birth_year return age result = calculate_age(2000, 2024) print(result) # Output: 24

Return Values (outputs)

Return statement sends a value back to the caller:

def square(number): return number ** 2 result = square(5) print(result) # Output: 25

Try Parameters & Returns

Default Parameters & Variable Arguments

Default Parameters

def greet(name="Friend"): print(f"Hello, {name}!") greet() # Uses default: "Friend" greet("Alice") # Uses "Alice"

Multiple Return Values

def get_person_info(): name = "John" age = 25 city = "NYC" return name, age, city # Unpacking returns name, age, city = get_person_info()

Key Takeaways

1. Define Functions: Use def keyword

2. Parameters: Inputs to the function

3. Return: Send result back

4. Default Values: Parameter defaults

5. Call Functions: Use function_name()
