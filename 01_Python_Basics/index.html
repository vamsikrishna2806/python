📦 Variables & Data Types

Variables are like containers that store information. Data types tell us what kind of data is stored.

Main Data Types in Python

Data Type Description Example
int Whole numbers age = 25
float Decimal numbers height = 5.9
str Text/Characters name = "John"
bool True or False is_student = True
list Ordered collection colors = ["red", "blue"]

🎨 Visual Understanding of Variables

Creating and Using Variables

# Creating variables
name = "Alice" # String variable

height = 5.6 # Float variable
is_student = True # Boolean variable

# Using variables
print(name)

String Operations

You can also perform operations on text (strings):

# Concatenating (joining) strings
first_name = "John"
last_name = "Doe"
full_name = first_name + " " + last_name
print(full_name) # Output: John Doe

# Repeating strings
print("Python" * 3) # Output: PythonPythonPython

📥 Input & Output

Getting Input from User

The input() function lets users give you information:

# Ask user for input
name = input("What is your name? ")
age = input("How old are you? ")

print("Hello, " + name)
print("You are " + age + " years old")
⚠️ Note: The input() function always returns text (string), even if the user types numbers. We'll learn how to convert this later!

Different Ways to Print

# Simple print
print("Welcome to Python!")

# Print multiple items
print("Name:", "John", "Age:", 25)

# Print with new lines
print("Line 1\nLine 2")

# Print with formatting (f-strings)
name = "Alice"
age = 30
print(f"My name is {name} and I am {age} years old")

Create a Simple Calculator

Use everything you learned to create a calculator that:

  • ✅ Takes two numbers as input
  • ✅ Adds them together
