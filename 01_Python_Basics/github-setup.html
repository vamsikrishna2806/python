🐙 Git & GitHub Setup

Create a repository on GitHub and push your local code

🎯 The Big Picture

Git tracks changes to your files on your computer. GitHub stores a copy online. You commit locally, then push to GitHub.

1. Installgit
2. Create repoon GitHub
3. Initgit init
4. Commitgit commit
5. Connectgit remote add
6. Pushgit push
⏱️ About 15 minutes the first time. After that, a push takes two commands.

1️⃣ Install Git

1

Open git-scm.com/downloads and download the Windows installer.

2

Run it and keep the default options. Click Next until Install, then Finish.

3

Check it worked. Open a terminal and run:

git --version

2️⃣ Tell Git Who You Are

Every commit records a name and email. Use the same email as your GitHub account.

# Replace with your own name and GitHub email git config --global user.name "Your Name" git config --global user.email "you@example.com"
💡 Check the settings with git config --global --list. Without these, the first commit fails with "Author identity unknown".

3️⃣ Create an Empty Repository on GitHub

1

Sign in at github.com. Click the + icon (top right) → New repository.

2

Enter a Repository name (for example python). Choose Public or Private.

3

Leave these unticked: Add a README, Add .gitignore, Add a license. Your local folder already has files, and ticking them creates a conflict on the first push.

4

Click Create repository. Copy the URL shown, for example https://github.com/your-username/python.git.

4️⃣ Create a Personal Access Token

GitHub no longer accepts your account password for pushing. Use a token instead.

1

Go to github.com/settings/tokens → Generate new token (classic).

2

Give it a name, set an expiry, and tick the repo scope.

3

Click Generate token and copy it right away. GitHub shows it only once.

🔐 Keep the token secret. Anyone with it can push to your repositories. Do not paste it into chat, screenshots, or code files. Do not put it in the URL you save. If it was ever shared, delete it on the same settings page and create a new one.

5️⃣ Initialize Git in Your Local Folder

Open a terminal in the folder you want to upload (for example D:\python).

Optional: ignore files you should not upload

Create a file named .gitignore in the folder with lines like these. Git will skip matching files.

__pycache__/ *.pyc .ipynb_checkpoints/ .venv/ venv/ .env

Initialize, stage and commit

# 1. Start tracking the folder git init # 2. Stage every file git add . # 3. Save a snapshot with a message git commit -m "Initial commit"
💡 Run git status at any time to see which files are staged, changed, or untracked.
⚠️ Warnings like "LF will be replaced by CRLF" are harmless. They only mean Windows line endings are being converted.

6️⃣ Connect to GitHub and Push

# 4. Name the main branch "main" git branch -M main # 5. Link your local folder to the GitHub repo (use your URL) git remote add origin https://github.com/your-username/python.git # 6. Upload the code git push -u origin main
!

When asked, enter:

Username: your GitHub username

Password: paste your token (the characters will not appear, this is normal)

✅ When it works you will see * [new branch] main -> main. Refresh your GitHub repo page and your files are there.
💡 Windows usually saves the token in Credential Manager, so you only type it once. The -u flag makes future pushes just git push.

🔁 Everyday Workflow

After the first setup, every change follows the same three steps:

git add . git commit -m "Describe what you changed" git push

Before you start working on a second machine, run git pull to get the latest changes.

🛠️ Troubleshooting

MessageMeaningFix
Author identity unknown Git does not know your name or email. Run the two git config --global commands in Step 2.
No commits yet in git status The repo exists but nothing has been committed. Run git add . then git commit -m "...".
failed to push some refs GitHub has commits (for example a README) that you do not have locally. Run git pull --rebase origin main, then push again. Or create the repo with no files.
403 Permission denied Windows is using a saved login for a different GitHub account. Open Credential Manager → Windows Credentials, delete the git:https://github.com entries, then push again and enter the right username and token.
remote origin already exists A remote is already set up. Check with git remote -v. To change it, run git remote set-url origin <new-url>.
src refspec main does not match any You have no commits yet, so there is no main branch. Commit first, then push.
[gone] next to the branch in git status -sb The local record of the remote branch is missing. Run git fetch origin.

✨ Checklist

  • Git installed and git --version works
  • Name and email set with git config --global
  • Empty repo created on GitHub (no README added)
  • Personal access token created and stored safely
  • git init, git add ., git commit done locally
  • git remote add origin and git push -u origin main succeeded
