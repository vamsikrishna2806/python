🛠️ Setup Guide

Install VS Code, Python, and the Jupyter extension — step by step

🎯 What You Will Install

1. VS Code

A free code editor from Microsoft. This is where you write Python.

2. Python

The language itself. VS Code runs your code using it.

3. Extensions

Python (run & debug) and Jupyter (notebooks with .ipynb files).

⏱️ Total time: about 15–20 minutes. You only do this once.

1️⃣ Install Python

Install Python first, so VS Code can find it.

1

Open python.org/downloads and click Download Python 3.x (any recent 3.10+ version).

2

Run the installer. Very important: tick "Add python.exe to PATH" at the bottom of the first screen.

3

Click Install Now, then Close when finished.

4

Check it worked. Open Command Prompt (press Win + R, type cmd) and run:

python --version

You should see something like Python 3.12.x.

⚠️ If you see "python is not recognized", reinstall Python and make sure Add to PATH is ticked.

2️⃣ Install VS Code

1

Open code.visualstudio.com and click Download for Windows.

2

Run VSCodeUserSetup-x64.exe. Accept the licence and click Next.

3

On the Select Additional Tasks screen, tick these boxes:

  • Add "Open with Code" to the right-click menu
  • Add to PATH
  • Register Code as an editor for supported file types
4

Click Install, wait, then Finish. VS Code opens automatically.

3️⃣ Install the Python Extension

This adds Python support: syntax colours, running files, debugging, and IntelliSense.

1

In VS Code, press Ctrl + Shift + X to open the Extensions panel (the squares icon on the left).

2

Type Python in the search box. Pick the one published by Microsoft.

3

Click the blue Install button.

✅ Test it: Create a new file hello.py, type print("Hello, World!"), then press ▶ Run (top right) or F5. You should see Hello, World! in the terminal.
⚠️ If VS Code asks "Select a Python interpreter", click it and choose the Python you installed (e.g. Python 3.12.x). Press Ctrl + Shift + P → type Python: Select Interpreter to change it later.

4️⃣ Install the Jupyter Extension

Jupyter lets you write code in cells and see results right below them. Great for learning and data work.

1

Open the Extensions panel again (Ctrl + Shift + X).

2

Search Jupyter and install the one published by Microsoft (it installs related packages automatically).

3

Install the Jupyter package for Python. Open a terminal in VS Code (Ctrl + `) and run:

pip install ipykernel jupyter

Create and run your first notebook

4

Press Ctrl + Shift + P → type Create: New Jupyter Notebook. Save it as practice.ipynb.

5

Type this in the first cell:

# My first notebook cell name = "Alice" print(f"Hello, {name}!")

Click the ▶ button on the left of the cell, or press Shift + Enter.

6

If asked to Select Kernel, choose Python Environments and then your Python version.

✅ You should see Hello, Alice! printed under the cell.
💡 Shortcuts inside notebooks:
Shift + Enter — run cell and move to next
Ctrl + Enter — run cell and stay
B — new cell below (in command mode, press Esc first)

✨ Final Checklist

  • Python installed and python --version works
  • VS Code installed and opens
  • Python extension installed (Microsoft)
  • Jupyter extension installed (Microsoft)
  • hello.py runs and prints a message
  • practice.ipynb runs a cell and prints a message
🎉 Your setup is complete. Head back to Python Basics and start coding!
