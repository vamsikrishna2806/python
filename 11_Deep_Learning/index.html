🧠 Neural Networks Basics

ADVANCED How Neurons Work

A Neural Network = Layers of mathematical neurons connected together

Brain Inspiration:
🧠 Your brain = 86 billion neurons
🤖 Neural net = Artificial neurons (mathematical functions)
🔗 Neurons pass signals to each other
📚 Learning = Adjusting connection strengths

The 3 Layers:
• Input Layer: Features going in (image pixels, text tokens)
• Hidden Layers: Process & learn patterns (1-100+ layers)
• Output Layer: Final predictions (classification, regression)

Simple Neural Network Code

from tensorflow import keras
from tensorflow.keras import layers

# Build a neural network
model = keras.Sequential([
    # Input: 784 features (28x28 image)
    layers.Dense(128, activation='relu'), # Hidden layer 1
    layers.Dense(64, activation='relu'), # Hidden layer 2
    layers.Dense(10, activation='softmax') # Output: 10 classes
])

# Compile & train
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy')
model.fit(X_train, y_train, epochs=10)

📚 Key Deep Learning Concepts

Activation Functions

ReLU: Most common, simple & fast
Sigmoid: For probabilities (0-1)
Softmax: For multi-class classification
Tanh: Similar to sigmoid, -1 to 1

Optimization & Learning

Gradient Descent: Adjusts weights to minimize error
Backpropagation: How error flows backward through network
Epoch: One pass through all training data
Batch Size: How many samples before updating weights
Learning Rate: How big are the weight updates

Challenges & Solutions

Overfitting: Memorizes data → Use Dropout, Early Stopping
Vanishing Gradient: Weights don't update → Use ReLU or LSTM
Requires GPUs: Training is slow → Use Google Colab, AWS
Needs lots of data: Deep learning hungry for data → Use transfer learning
