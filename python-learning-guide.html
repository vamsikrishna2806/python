📁 File Handling - Complete Guide

Reading & Writing Files - Best Practices

Always use context managers (with statement) to safely handle files.

# ✅ BEST PRACTICE - Context Manager (auto-closes file) with open('data.txt', 'r', encoding='utf-8') as f: content = f.read() # Reading line by line (memory efficient) with open('data.txt', 'r') as f: for line in f: print(line.rstrip()) # rstrip removes trailing \n # Read all lines into a list with open('data.txt', 'r') as f: lines = f.readlines() # Writing files with open('output.txt', 'w', encoding='utf-8') as f: f.write('Hello World\n') f.write('Second line\n') # Appending to existing file with open('data.txt', 'a') as f: f.write('\nAppended line') # Writing multiple lines at once lines = ['Line 1\n', 'Line 2\n', 'Line 3\n'] with open('output.txt', 'w') as f: f.writelines(lines)
💡 Tip: Always specify encoding='utf-8' for text files. Never rely on system default encoding.

File Modes Comprehensive Reference

'r' - Read Only

Read mode (default). File must exist. Pointer at start. Can't write.

'w' - Write

Write mode. Creates file or truncates if exists. Starts fresh.

'a' - Append

Append mode. Adds to end of file. Creates if doesn't exist.

'r+' - Read/Write

Read and write. File must exist. Pointer at beginning.

'w+' - Write/Read

Write and read. Truncates file if exists. Pointer at beginning.

'x' - Create

Create mode. Fails if file already exists. Creates new file.

'b' - Binary Mode

Add to any mode for binary files (images, videos, etc)

Example: 'rb', 'wb'

rb = read binary, wb = write binary

Statistical Hypothesis Testing

from scipy import stats import numpy as np # T-TEST (compare means of 2 groups) group1 = [85, 90, 88, 92, 89] group2 = [78, 82, 80, 79, 81] t_statistic, p_value = stats.ttest_ind(group1, group2) if p_value < 0.05: print('Means are significantly different') else: print('No significant difference') # ANOVA (compare means of 3+ groups) group1 = [85, 90, 88] group2 = [78, 82, 80] group3 = [92, 95, 91] f_stat, p_value = stats.f_oneway(group1, group2, group3) # CHI-SQUARE TEST (categorical) observed = [10, 20, 30, 40] expected = [25, 25, 25, 25] chi2, p_value = stats.chisquare(observed, expected) # CORRELATION TEST x = [1, 2, 3, 4, 5] y = [2, 4, 5, 4, 6] correlation, p_value = stats.pearsonr(x, y) print(f'Correlation: {correlation:.3f}, p-value: {p_value:.3f}') # NORMAL DISTRIBUTION TEST data = np.random.normal(0, 1, 100) statistic, p_value = stats.shapiro(data) print('Data is normally distributed' if p_value > 0.05 else 'Not normal')

Project 5: Recommendation Engine

from sklearn.metrics.pairwise import cosine_similarity import pandas as pd import numpy as np # USER-ITEM MATRIX (ratings) ratings = pd.DataFrame({ 'User1': [5, 4, 0, 3, 0], 'User2': [4, 0, 3, 4, 5], 'User3': [3, 5, 4, 0, 4], 'User4': [0, 4, 5, 5, 3], 'User5': [4, 3, 0, 4, 5] }, index=['Movie1', 'Movie2', 'Movie3', 'Movie4', 'Movie5']) # FILL MISSING RATINGS ratings_filled = ratings.fillna(ratings.mean()) # CALCULATE SIMILARITY user_similarity = cosine_similarity(ratings_filled.T) user_sim_df = pd.DataFrame(user_similarity, index=ratings.columns, columns=ratings.columns) # RECOMMEND FOR USER1 user = 'User1' similar_users = user_sim_df[user].sort_values(ascending=False)[1:].index recommendations = ratings.loc[ratings[user] == 0].index scores = [] for movie in recommendations: score = 0 for similar_user in similar_users: if ratings.loc[movie, similar_user] > 0: score += ratings.loc[movie, similar_user] scores.append(score) top_recommendations = pd.Series(scores, index=recommendations).sort_values(ascending=False) print(f'Top recommendations for {user}:') print(top_recommendations.head())
